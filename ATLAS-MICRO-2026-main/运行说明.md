# ATLAS 仿真器运行说明

这份说明只覆盖已经在本机跑通的周期级仿真：云侧一颗 chip 上的 GEMM。热仿真、TileLang 和 ATLang 还没装，不在这里。

所有命令都在仓库根目录执行：

```bash
cd /data2/nirunheng/Project/ATLAS-MICRO-2026-main/ATLAS-MICRO-2026-main
```

## 1. 当前已经准备好的依赖

系统自带的 CMake 3.22 太旧。本机使用：

```text

/usr/bin/g++                                 # 11.4.0
/opt/anaconda3/bin/python3                   # 3.12.4，已有 PyYAML
```

## 2. 编译

```bash
CMAKE=/opt/anaconda3/envs/lerobot_env/bin/cmake

"$CMAKE" -S simulator -B simulator/build \
  -DCMAKE_BUILD_TYPE=Release \
  -DPYTHON_EXECUTABLE=/opt/anaconda3/bin/python3

"$CMAKE" --build simulator/build --parallel "$(nproc)"
```

编完后主要产物是：

- `simulator/build/bin/test_core`：直接读三份 YAML 跑一次仿真。
- `simulator/build/lib/atlasim.cpython-312-x86_64-linux-gnu.so`：Python 里的 `atlasim.Chip`。
- `simulator/build/lib/libatlasim-lib.so`、`libramulator.so`：运行时要能找到的动态库。

BookSim 编译时会打印 `register` 的警告，可以忽略。

## 3. 跑一次现成的 GEMM

这是仓库自带的单算子例子，不经过模型解析和 tiling 搜索。

```bash
export LD_LIBRARY_PATH="$PWD/simulator/build/lib:${LD_LIBRARY_PATH:-}"

./simulator/build/bin/test_core \
  configs/architecture/chip/test_chip_16ch.yaml \
  configs/operator_yaml/gemm_comp/gemm.yaml \
  configs/operator_yaml/gemm_comp/gemm_data.yaml \
  /tmp/atlas_gemm.log
```

三个输入分别是芯片配置、算子描述和张量摆放。日志写到 `/tmp/atlas_gemm.log`。

本机一次运行的结果是 **48446 cycle**。0 号核的 DRAM 带宽利用率约 17.3%。日志末尾还能看到各部件周期、能耗和算术强度。

同样的调用用 Python：

```bash
export PYTHONPATH="$PWD/simulator/build/lib:${PYTHONPATH:-}"
export LD_LIBRARY_PATH="$PWD/simulator/build/lib:${LD_LIBRARY_PATH:-}"

python3 - << 'PY'
import atlasim
chip = atlasim.Chip(
    "configs/architecture/chip/test_chip_16ch.yaml",
    "configs/operator_yaml/gemm_comp/gemm.yaml",
    "configs/operator_yaml/gemm_comp/gemm_data.yaml",
    "/tmp/atlas_gemm_py.log",
)
perf = chip.simulate()
print(perf.e2e_stats.e2e_cycles, perf.e2e_stats.e2e_energy)
PY
```

这里打印的是 16 个核合计后的能耗，所以能量数值比日志里单核的统计大。周期仍是 `48446`。

`Chip` 的四个参数是芯片 YAML、算子 YAML、数据摆放 YAML、日志路径。日志路径可以省略。

## 4. 跑完整的一层推理

`tests/inference_test_auto.py` 会先做 tiling 搜索，再调用上面同一个 `Chip.simulate()`。它不需要 TileLang。

```bash
export PYTHONPATH="$PWD/simulator/build/lib:${PYTHONPATH:-}"
export LD_LIBRARY_PATH="$PWD/simulator/build/lib:${LD_LIBRARY_PATH:-}"

python3 tests/inference_test_auto.py
```

脚本里写死了两个负载：

- 云侧：`configs/models/opt_66b.json`，batch 8，上下文 4096，系统配置是 `configs/architecture/system/test_cloud_system.yaml`。
- 边侧：`configs/models/opt_6.7b.json`，batch 8，上下文 2048。

结果写到 `kick_the_tires/`。这个入口会反复创建 `Chip` 做 tiling，耗时比上面的单算子例子长得多。
